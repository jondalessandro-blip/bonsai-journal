In the Bonsai Journal app, in artifacts/bonsai-journal/src/lib/speciesMatcher.ts, I want to simplify how the "From your collection" species suggestions are built. Right now, the function getSpeciesSuggestionsFromTrees tries to match each tree's Name and Species text against the curated reference list, and if it finds a loose match (even just a single generic word), it replaces that tree's own species information with the curated entry's information. This causes real bugs: a tree's actual species can get silently swapped for an unrelated curated species, or a tree can disappear from suggestions entirely because it got merged into a curated entry that's already shown elsewhere.

Please change getSpeciesSuggestionsFromTrees so it no longer looks at the curated reference list at all. It should simply return each tree's own actual Name and Species text, exactly as stored, with no substitution. Deduplicate only when two different trees have the exact same Species text (case-insensitive, trimmed), keeping the first one encountered. If a tree has no Species text, skip it, same as before. The commonName for each returned entry should be the tree's own Name if it has one, otherwise fall back to using its Species text as the commonName too. The scientificName for each returned entry should always be the tree's own Species text. Aliases should be an empty array.

Since the old matching logic is being removed, please also delete the now-unused helper functions findBestMatch and longestMatchingPhrase from this file, since they would otherwise become dead code. Leave everything else in the file untouched, including getSpeciesSuggestions, phrasesFor, and normalize, since those are still used for matching typed queries against the curated reference list and that part is working correctly.

Do not change anything in TreeForm.tsx, the OpenAPI spec, or the backend. This is a small, self-contained frontend fix to one function in one file.

Please do not push, publish, or modify anything on the remote GitHub branch. Commit your changes locally only, and report back the commit hash.
